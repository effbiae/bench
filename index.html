These are the descriptions for nbody and knucleotide benchmarks.

Note the python times lie in a tight box compared to k-like languages growler and goal. This highlights that array languages have strengths and weaknesses. The k languages beat python in the knucleotide benchmark but lost out in nbody, I believe because python allows in-place modification of the bodies' properties. Can you make them faster?

Python and gcc are included in the game as the languages to beat.
